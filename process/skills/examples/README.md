# Worked examples

Finished artifacts, so the templates are not the only thing anyone sees.

> **These are a composite, not a client engagement.** The project below —
> "Meridian", a regulated lender's servicing portal — is assembled from the shape of
> real work with all client specifics removed and all numbers invented for
> illustration. Nothing here is confidential and nothing here is a real measurement.
> Every artifact carries the same notice.
>
> In an interview, say this out loud. Being visibly careful with a former client's
> data is worth more than the example itself.

| # | Artifact | Skill | Shows |
|---|---|---|---|
| 01 | [Project brief](01-project-brief.md) | `brief-intake` | UNRESOLVED metrics, ranked assumptions, three questions |
| 02 | [Drift report](02-drift-report.md) | `ds-inventory` | Token diff, coverage, one primitive closing eleven findings |
| 03 | [Audit report](03-audit-report.md) | `heuristic-audit` | Severity × frequency, cost column, sequenced fixes |
| 04 | [Synthesis](04-synthesis.md) | `research-synthesis` | n of N, signal strength, contradicting the brief |
| 05 | [State matrix](05-state-matrix.md) | `flow-map` | Full state coverage, "n/a" with reasons |
| 06 | [Handoff](06-handoff.md) | `handoff-spec` | Rules not redlines, gaps marked as gaps |
| 07 | [Critique](07-critique.md) | `critique` | Seven fronts, ranked, each with a proposal |

## Reading order for a demo

01 → 02 → 07. Intake shows the discipline, the drift report shows the analysis,
the critique shows the self-scepticism. The other four are there if someone asks.
