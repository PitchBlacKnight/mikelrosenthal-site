Worked examples

Finished artifacts, so the templates are not the only thing anyone sees.

These are a composite, not a client engagement. The project below — "Meridian", a regulated lender's servicing portal — is assembled from the shape of real work with all client specifics removed and all numbers invented for illustration. Nothing here is confidential and nothing here is a real measurement. Every artifact carries the same notice.

In an interview, say this out loud. Being visibly careful with a former client's data is worth more than the example itself.

Reading order for a demo

01 → 02 → 07. Intake shows the discipline, the drift report shows the analysis, the critique shows the self-scepticism. The other four are there if someone asks.
