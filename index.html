01The Premise

Every project I've done follows the same five steps.
AI made them a lot faster.

What used to take a sprint of static comps now takes an afternoon of working code. More of the loop happens in the real thing, and I get the hours back for the craft.

1.Define. The real goal, the user, the constraints, before any pixels.
2.Build. Working code early, on the hardest screen, so the team reacts to the real thing.
3.Test. Put it in front of people. Keep what survives.
4.Design. Type, spacing, color, motion. Every state: loading, empty, error, edge. Then make it a system a whole team can build from.
5.Ship. Prototype to production front-end with Claude Code, shipped alongside engineering.
